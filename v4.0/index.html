1. TrackEd Dashboard — Rebuilt Around the Feedback

TrackEd is not another EdTech product; it is a reflective M&E layer above EdTech tools. It helps schools understand how different tools are being used, whether they are supporting learning, and what classroom conditions explain the difference.

Core QuestionWhat helps learning?
Primary UserTeacher + School
Measurement EthicMirror, not monitor
Evidence ModeLow-burden triangulation
Design correction: This version moves away from the earlier 12-dimensional IMPACT+ style scorecard and places REFLECTIVE at the centre. Scores are no longer used to rank teachers; they are used to generate prompts for improvement.

2. Design Brief: What the Dashboard Must Do

Feedback ReceivedDesign Response in TrackEd
The tool should not become an EdTech intervention of its own.TrackEd only captures, interprets and reflects evidence from existing tools and classroom processes.
Teachers will not complete long questionnaires regularly.The dashboard uses one-minute pulse check-ins, class-level reflections, and optional voice notes.
Schools need to know which activities enable engagement and which enable improvement.The dashboard separates engagement evidence from learning evidence and shows likely enablers.
EdTech does not work by itself.Every session log records teacher role, peer discussion, task type, language support and feedback.
Data should not become surveillance.No teacher ranking, optional student voice, consent flags, aggregated reporting and supportive language.
Different EdTech tools need different evidence.Use-case screens show different evidence patterns for Khan Academy, DIKSHA, Byju's, PhysicsWallah and YouTube.

5. Teacher Pulse Logger: One-Minute Check-In

The pulse logger replaces long questionnaires. It captures classroom energy and engagement as a quick, repeated signal that can be triangulated with timetable, subject, tool, and assessment data.

Mirror prompt: Low energy was recorded after a sports period. Consider whether the next activity should begin with a short recap or energiser rather than interpreting this as poor engagement.

8. Cross-Platform M&E Layer

TrackEd does not duplicate platform dashboards. It converts platform-level data into M&E questions and adds classroom context that EdTech tools usually miss.

9. Classroom Use Cases

Use Case A: Khan Academy — Class 7 Decimals

Session ContextTrackEd CaptureGenerated Insight
Students work in pairs because devices are limited.Mode: shared devices; LO: decimal word problems; purpose: practice.Pair work increased peer explanation but reduced individual practice time.
Students solve direct operations but struggle with word problems.Teacher reflection + platform quiz score.Next class should focus on reading and interpreting word problems.

Use Case B: DIKSHA / Video Resource — Class 7 Science

Session ContextTrackEd CaptureGenerated Insight
Teacher uses video/simulation on separation of substances.Tool: DIKSHA/video; mode: whole-class; follow-up group task.Video supported concept introduction, but application improved through group examples.
Students apply concept to tea leaves, saltwater, sieving.Competency: application to daily life.Students need more hands-on practice for transfer.

Use Case C: PhysicsWallah / YouTube — Homework Support

Session ContextTrackEd CaptureGenerated Insight
Students watch lecture outside class.Purpose: homework support; evidence: student reflection and short quiz.High exposure does not necessarily show understanding; follow-up classroom check is needed.

11. Scoring Logic: From Scores to Prompts

TrackEd should avoid a single punitive score. It can still show indices, but each score must produce an explanation and a reflective next step.

ScoreCalculationInterpretationOutput Language
Access ReadinessDevice + connectivity + language support + shared-use feasibilityWhether children had opportunity to benefit"Some students may not have had equal access."
Use QualityPurpose + mode + duration + teacher mediationWhether EdTech use was passive or active"Consider adding discussion after video viewing."
Engagement SignalEnergy pulse + participation + questions + peer supportWhether students were involved"Engagement was lower post-lunch; context may matter."
Learning SignalPre/post or platform score + teacher-identified misconceptionsWhether learning improved"Procedural skill improved; word problems need support."
Reflection QualityTeacher note contains observation + reason + next actionWhether data closed the learning loop"Next-step reflection recorded."
Dashboard rule: No teacher leaderboard. No red label attached to an individual teacher. Red flags are attached to support needs, not people.

12. Mirror Insights: Supportive Reporting Language

Instead of: Student engagement was poor.

TrackEd says: Engagement appeared lower than usual. This was a post-lunch period and students had just returned from sports. Consider a short recap, energiser, or peer task before beginning individual practice.

Instead of: Teacher did not use EdTech effectively.

TrackEd says: The digital resource was used mainly for viewing. A follow-up question or group task may help convert exposure into learning.

Instead of: Students failed the assessment.

TrackEd says: Students attempted procedural questions successfully but struggled with application. The next session may focus on examples from daily life.

20. Pilot Setup

ComponentRecommended Setup
Duration8–12 weeks
Schools6–10 schools with different levels of device access and EdTech maturity
ToolsAt least three: Khan Academy, DIKSHA and one commercial/open video platform
GradesGrades 6–8
Data collectionPulse every session; session reflection weekly or after meaningful EdTech use; observation monthly; assessment baseline/endline
Success criteriaTeachers complete pulse in under one minute; at least 70% session evidence completeness; dashboards used in monthly school review
EthicsConsent, opt-out, aggregate dashboards, no rankings, no intrusive surveillance
